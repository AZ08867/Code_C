# array2function — 数组与函数指针示例

本目录包含若干示例，演示如何在 C 中将数组传递给函数、使用函数指针以及相关的实践用法。

## 快速开始

```sh
clang *.c -o array2function.exe
.\array2function.exe
```

## 主要文件

- `point.c`：与指针、数组与地址相关的示例代码。
- `train.c`：训练示例，演示如何把数组与回调（函数指针）组合使用以实现灵活行为。

## 说明与建议

- 先阅读源文件顶部的注释以了解每个示例的输入与预期输出。
- 使用编译命令单独运行某个示例，方便调试与学习。
- 修改示例以探索不同的数组边界情况与函数指针用法。
