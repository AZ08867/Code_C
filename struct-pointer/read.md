# struct-pointer — 结构体与指针成员示例

在 C 中使用结构体指针访问成员，并演示对整型数组的动态分配与释放。示例包括通过指针访问结构体成员（`->`）和基本的内存管理实践。

## 快速开始

```sh
clang main.c -o struct_pointer.exe
.\struct_pointer.exe
```

## 主要文件

- `main.c`：定义 `struct Point`，演示通过指针访问结构体成员；同时读取用户输入 `n`，使用 `malloc` 分配一个整数数组并初始化与打印，最后 `free` 并将指针置为 `NULL`。

## 说明

- 结构体指针访问：当有一个指向结构体的指针 `ptr` 时，使用 `ptr->x` 而不是 `(*ptr).x` 或 `ptr.x`。
- 动态分配：示例中使用 `malloc(n * sizeof(int))` 分配数组；程序在分配失败时会做空指针检查并打印错误。
- `scanf_s`：源码中使用了 `scanf_s`（Windows 安全函数），在跨平台或用 `gcc/clang` 编译时可替换为标准 `scanf("%d", &n);`。

## 运行时注意

- 请确保输入的 `n` 合理且系统有足够内存。
- 分配返回 `NULL` 时应做适当处理（当前示例打印错误并返回非 0 值）。
- 在释放后将指针设为 `NULL` 有助于避免悬空指针。
